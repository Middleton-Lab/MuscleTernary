# Compute 3D vector cross product

Compute the vector cross product between x and y, and return the
components indexed by i. See:
https://stackoverflow.com/a/21736807/168137

## Usage

``` r
CrossProduct3D(x, y, i = 1:3)
```

## Arguments

- x:

  Vector or matrix

- y:

  Vector or matrix

- i:

  Indices

## Value

Cross product matrix
