# Calculate rotation matrix

Calculate the rotation matrix required to rotate vector A onto vector B.
Both vectors will be normalized to a unit vectors prior to rotation.
See: http://math.stackexchange.com/a/897677/6965

## Usage

``` r
RU(A, B)
```

## Arguments

- A:

  Vector (usually the unit vector)

- B:

  Vector

## Value

U rotation matrix between A and B
